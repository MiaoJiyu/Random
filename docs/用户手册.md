# 加权随机数生成器 · 用户手册

基于 Node.js 全栈重写的加权随机数生成器，提供**网页版**与 **Electron 桌面版**两套界面，共享同一套前端代码。配置与历史记录保存在云端 MySQL，无需登录、开箱即用。

---

## 一、运行环境准备

- 安装 [Node.js](https://nodejs.org/)（建议 18 LTS 及以上版本，Windows 安装时勾选 “Add to PATH”）。
- 项目已内置云数据库连接配置（`.env`），无需自行搭建数据库。

## 二、首次启动（自动安装依赖）

进入项目目录后，根据需求双击以下脚本之一：

| 脚本 | 作用 |
| --- | --- |
| `start-web.bat` | 启动**网页版**（本地服务 + 浏览器） |
| `start-desktop.bat` | 启动 **Electron 桌面客户端** |
| `build-win.bat` | 打包生成 Windows 安装程序（`dist\`） |

> 首次运行会自动执行 `npm install`，请保持联网。依赖安装完成后即可使用。
> Linux / macOS 可使用 `./start.sh` 启动网页版。

## 三、网页版使用

1. 双击 `start-web.bat`，控制台显示 `服务已启动：http://localhost:3000`。
2. 打开浏览器访问 `http://localhost:3000` 即可。
3. 停止：在控制台按 `Ctrl + C`。

## 四、桌面版使用

双击 `start-desktop.bat`，程序会自动启动后端并打开桌面窗口，体验接近原生应用，且**完全离线可用**（仅有“云端同步”功能需要联网）。

## 五、三大视图说明

顶部导航可在 **抽取 / 数据 / 统计** 三个视图间切换。右上角显示云端连接状态：绿色“云端已连接”或红色“云端离线（本地可用）”。

### 1. 抽取视图

- **大转盘模式（默认）**：点击中央圆形“START”或“开始抽取”，转盘旋转并减速停在预选结果上。
- **数字闪动模式**：点击“数字闪动”切换，界面以约 5 秒数字闪动呈现结果，可在过程中点击“停止”立即定格。
- 实际结果由加权算法在动画开始前**预先决定**，转盘/闪动仅为视觉表现。
- 动画结束后结果定格并弹出提示，同时异步写入云端历史（离线时暂存本地，联网后自动同步）。

### 2. 数据视图

- **统计信息条**：实时显示总数、总权重、平均概率。
- **数字表格**：数字 / 权重 / 概率三列；可直接在“权重”列输入框修改权重（回车或失焦生效）；行尾 `✕` 删除该行；勾选行首复选框进行多选。
- **编辑随机数范围**：
  - 添加单个（弹窗设置权重）
  - 删除单个
  - 批量区间（`起 ~ 止` 自动处理大小顺序）
  - 列表/正则（`1,3,5-9` 形式，逗号分隔、`-` 表示区间）
  - 区间删除
- **编辑权重**：单数字权重设置、多选编辑、统一权重（一键全部设为同一权重）。
- **导入 / 导出 / 云端**：
  - 导入 JSON / 导出 JSON（配置含模式与数字列表）
  - 导入 CSV / 导入 Excel（第一列数字、第二列权重，权重缺失默认 1）
  - 下载模板（示例 `template.csv`）
  - 保存到云端 / 从云端拉取（激活配置）
  - 清空所有数据（二次确认）
- **云端配置管理**：列出云端所有配置，可激活、删除；新建配置（以当前本地数据保存）。

### 3. 统计视图

- 顶部汇总卡片：抽取总次数、最近一次、最高频数字。
- **柱状图**：各数字抽取次数分布。
- **饼图**：各数字占比。
- **历史记录**：按时间倒序分页展示（时间 / 数字 / 权重），可清空历史（二次确认）。

## 六、云端配置同步

- **本地优先**：本地配置保存在浏览器/桌面端的 `localStorage`，刷新不丢失。
- **拉取**：数据视图“从云端拉取”或抽取视图“拉取到本地”，将云端激活配置覆盖到本地。
- **上传**：数据视图“保存到云端”或抽取视图“本地上传云端”，将本地配置写入云端并设为激活。
- **多份配置**：在云端配置管理中新建、激活、删除多份配置，便于不同场景切换。

## 七、打包 Windows 安装程序

1. 在 Windows 开发机上确保依赖已安装（`npm install`）。
2. 双击 `build-win.bat`，执行 `electron-builder` 打包。
3. 生成的安装程序位于 `dist\` 目录（NSIS 安装包），双击即可安装到任意目录。

> 说明：因 Electron 二进制较大，打包需联网下载；沙箱环境已跳过该下载，打包步骤请在 Windows 开发机执行。

## 八、常见问题

- **端口被占用**：网页版默认 3000 端口，占用时修改 `.env` 中的 `PORT` 后重启。
- **云端离线**：顶部显示“云端离线”时，抽取、数据编辑、转盘等本地功能均正常，仅云端同步不可用；恢复网络后离线记录会自动补传。
- **导入无反应**：请确认文件第一列为数字；表头等非数字行会被自动跳过。
